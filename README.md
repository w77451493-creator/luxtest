## English

### What is Aholo Lux3D?

Aholo Lux3D generates a 3D model from one image or a text description. You can preview it in the browser, export GLB, and use the same capability from a coding agent.

Website: https://lux3d.aholo3d.com

### Install

Paste this into a task in Codex, Claude Code, WorkBuddy, or another coding agent:

```text
/goal Read https://raw.githubusercontent.com/w77451493-creator/luxtest/main/AGENTS.md and install Aholo Lux3D.
```

The agent installs two parts:

- **Aholo Lux3D**, the skill that plans, generates, and delivers the model.
- **Aholo Lux3D MCP**, the connection the agent uses to call Lux3D.

When the agent asks for an API key, enter the China-region key in the agent's own credential setting. Do not paste the key into the chat. After installation, start a **new** task before using it. Paid generation uses `LUX3D_GLOBAL_API_KEY`.

If Aholo Lux3D is already installed, keep the existing copy. Do not install it again.
